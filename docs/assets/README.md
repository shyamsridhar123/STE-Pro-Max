### Generation prompt

Use case: ads-marketing. Asset: a premium widescreen GitHub README hero banner
for the developer tool STE-Pro Max. Create an art-directed editorial composition,
not a generic SaaS gradient. 21:9 landscape. Near-black charcoal with subtle warm
paper grain, warm ivory lettering, and a disciplined copper-orange accent.

Left: enormous precisely typeset sans-serif headline on two lines, exactly
“Complex ideas.” and “Clear explanations.” Above: small widely spaced monospace
wordmark “STE-PRO MAX”. Below: “WRITE / VISUALIZE / EXPLAIN”.

Right: a dimensional still life of three thin ivory and charcoal editorial sheets
in a restrained architectural arrangement: source-document marks, a line-and-node
technical diagram, and a sequential narrative strip. A single fine copper line
flows from dense source marks into the clean diagram and narrative, expressing
complexity becoming understanding. Carefully composed shadows, precise edges,
tactile materials, sophisticated depth, and confident negative space.

This is conceptual brand artwork, not a screenshot. Keep typography inside
generous safe margins and readable at README width. No other labels, numbers,
provider logos, badges, watermarks, statistics, claims, signatures, or unrelated
product names. No blue/purple gradients, neon, robots, brains, rockets, mascots,
or sparkles. Balanced, quiet, powerful, memorable.
