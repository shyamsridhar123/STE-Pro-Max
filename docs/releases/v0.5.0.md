# STE-Pro Max v0.5.0 — Make the mechanism visible

**Line Studio is now part of the native plugin.** Turn an explanation into
original interactive SVG, without adding a framework or a Python setup step.

- **Retry Observatory:** follow 1 → 3 → 9 → 27 → 81, then compare one retry
  owner. Play, pause, scrub, change the assumptions and save a static SVG.
- **Six original patterns:** stack, field, layers, signal, orbit and flow.
  Pointer, keyboard and touch controls keep the figure inspectable.
- **Reader-first behavior:** reduced motion, a static/no-JS reading path,
  printable assumptions, light/dark themes and offline HTML.
- **Same STE foundation:** clear language, preserved uncertainty and
  evidence-linked storytelling.

## Install or update

Use the [native plugin guide](../PLUGINS.md). Existing v0.4.0 pins do not
automatically advance; select v0.5.0 to get all four skills.

## Downloads

Get the assets from the [GitHub release](https://github.com/shyamsridhar123/STE-Pro-Max/releases/tag/v0.5.0):

- `ste-examples.zip` — seven standalone HTML examples and source notes.
- `ste-pro-max.zip` — the whitelisted source plugin for local/offline installation.
- `source-verification.json` — exact commit, tag and archive integrity.
- `native-lifecycle-verification.json` — tested install/discovery and their limits.
- `SHA256SUMS` — checksums for the attached archives and verification files.

The retry example is an illustrative persistent-failure model, not telemetry
or a resilience guarantee. SVG export is static, not video. Host model access,
permissions and privacy rules still apply; no AI-generation or universal
accessibility claim is implied by installation checks.

The existing v0.4.0 tag and release assets remain unchanged.
