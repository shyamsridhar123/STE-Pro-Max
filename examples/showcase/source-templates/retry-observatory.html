A visual proof of a small model, not production telemetry. Every attempt fails. Every retrying layer exhausts its budget. An upstream retry starts fresh downstream budgets. Tiles count cumulative calls, not concurrent requests or elapsed time.

What this model assumes
  • One original request and serial layers, each calling only the next layer.
  • No early success, deadlines, cancellation, caching, circuit breakers, deduplication, or shared retry budget.
  • In the comparison, only the outermost layer retries. Other layers forward once.

Fewer attempts is not a resilience guarantee or a production policy recommendation. The animation is explanatory pacing, not a simulated request trace.
