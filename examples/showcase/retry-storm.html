Source, assumptions & accessible data

Source: an arithmetic example authored for this showcase, not an observed incident. The model source (JSON) records the inputs and assumptions.

  • A single request passes through a chain of serial layers to one backend. The backend fails on every attempt.
  • Each layer makes up to the selected number of total attempts per incoming call, including its first attempt. Persistent failure exhausts every attempt budget.
  • Every upstream retry starts the full downstream sequence again. There are no shared retry budgets, early exits, deadlines, cancellation, caching, circuit breakers, or deduplication in this model.
  • In the comparison, the same layers and backend remain. Only the top layer owns retries; each other layer forwards each incoming call exactly once.
  • The model counts attempts, not elapsed time, concurrency, throughput, success probability, or production performance. It makes no resilience guarantee.

With A = 3 total attempts and L = 4 layers: A^L = 3^4 = 81 backend attempts. With one owner: A × 1^(L−1) = 3 backend attempts.

Each retrying layer allows 2 retries per incoming call. The 81 backend attempts include the first backend call and 80 additional backend calls; this is not 80 retries configured at a single layer.
